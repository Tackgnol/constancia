# Channel / Event / User Wiring — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the Discord bot's `/setup` command, the frontend war room's event board, and the event creation form to real database records instead of hardcoded demo data.

**Architecture:** A new `POST /bot/setup-channel` endpoint upserts campaign + channel records from Discord context. The frontend `war-room-layout.tsx` clientLoader fetches channels and events alongside campaigns; child routes (`play.tsx`, `setup.tsx`) read from the shared `WarRoomContext`. Demo routes remain fully hardcoded via an `campaignId === ''` sentinel.

**Tech Stack:** Fastify + Prisma (backend), discord.js (bot), React Router 7 clientLoader + Orval-generated fetch client (frontend), Vitest (tests), Orval (code generation)

**Spec:** `docs/superpowers/specs/2026-04-19-channel-event-user-wiring-design.md`

```ts
app.post<{ Body: SetupChannelBody }>(
  '/setup-channel',
  {
    schema: {
      tags: ['bot'],
      summary: 'Upsert campaign and channel from Discord context',
      operationId: 'setupChannel',
      body: setupChannelBodySchema,
      response: {
        200: singleResponseSchema(setupChannelDataSchema),
      },
    },
  },
  async (request) => {
    const prisma = getPrismaClient();
    const { guildId, guildName, discordChannelId, channelName, campaignName, gameSystemId } =
      request.body;

    const existingCampaign = await prisma.campaign.findUnique({
      where: { discordGuildId: guildId },
      select: { id: true },
    });

    const campaign = await prisma.campaign.upsert({
      where: { discordGuildId: guildId },
      create: { name: campaignName, discordGuildId: guildId, gameSystemId },
      update: {},
      select: { id: true, name: true, discordGuildId: true, gameSystemId: true },
    });

    const existingChannel = await prisma.channel.findUnique({
      where: { discordChannelId },
      select: { id: true },
    });

    const channel = await prisma.channel.upsert({
      where: { discordChannelId },
      create: { name: channelName, discordChannelId, campaignId: campaign.id, type: 'main' },
      update: {},
      select: { id: true, name: true, discordChannelId: true, campaignId: true, type: true },
    });

    return {
      status: 'ok',
      data: {
        campaign,
        channel,
        created: {
          campaign: existingCampaign === null,
          channel: existingChannel === null,
        },
      },
    };
  },
);
```

## Task 5: Bot — create `commands/setup.ts`

**Files:**

- [ ] **Step 1: Create the handler**

Create `apps/bot/src/commands/setup.ts`:

```ts
import { MessageFlags, type ChatInputCommandInteraction, type InteractionDeferReplyOptions } from 'discord.js';
import { setupChannel } from '../api/generated/endpoints/bot/bot.js';
import { botRequestOptions } from '../api/bot-headers.js';

export async function handleSetup(interaction: ChatInputCommandInteraction): Promise<void> {
  await interaction.deferReply({ flags: MessageFlags.Ephemeral } as InteractionDeferReplyOptions);

  const guildId = interaction.guildId;
  if (!guildId) {
    await interaction.editReply('This command can only be used in a server.');
    return;
  }

  const campaignName = interaction.options.getString('name', true);
  const gameSystemId = interaction.options.getString('system', true);
  const guildName = interaction.guild?.name ?? guildId;
  const discordChannelId = interaction.channelId;
  const channelName =
    interaction.channel && 'name' in interaction.channel
      ? (interaction.channel.name ?? discordChannelId)
      : discordChannelId;

  try {
    const result = await setupChannel(
      {
        guildId,
        guildName,
        discordChannelId,
        channelName,
        campaignName,
        gameSystemId,
      },
      botRequestOptions(),
    );

    const { campaign, channel, created } = result.data;
    const campaignNote = created.campaign ? ' *(campaign created)*' : '';
    const channelNote = created.channel ? ' *(channel registered)*' : ' *(channel already registered)*';

    await interaction.editReply(
      `✓ Campaign: **${campaign.name}**${campaignNote} | Channel: **#${channel.name}**${channelNote}`,
    );
  } catch (error) {
    console.error('Setup command error:', error);
    await interaction.editReply('Failed to register the channel. Please try again later.');
  }
}
```
