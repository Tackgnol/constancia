# Domain docs

Constancia uses a single-context domain layout.

Before exploring architecture or implementing domain behavior:

- Read `CONTEXT.md` when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- Use the glossary's exact domain vocabulary.
- Explicitly flag proposals that contradict an ADR.

Missing domain files are created lazily as terminology and decisions crystallize; their absence does not block work.
